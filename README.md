# 📅 スケジュール＆家計簿アプリ（Streamlit + Supabase）

このアプリは **Streamlit** と **Supabase** を使用した、  
「予定管理」と「家計簿（支出・収入）」を統合した Web アプリです。

月別カレンダーで予定と収支をまとめて確認できます。

---

## ✨ 主な機能

### 🗓 予定管理
- 日付・開始時刻・終了時刻を指定して予定を登録
- カテゴリ別（仕事／勉強／プライベート／その他）に管理
- 過去の予定は自動削除

### 💰 支出管理
- 日付・金額・カテゴリ別に支出を記録
- 食費・交通費・買い物などに分類可能

### 💵 収入管理
- 給料・お小遣いなどの収入を記録
- カテゴリ別に管理

### 📅 カレンダー表示
- 月別カレンダーに以下を表示
  - その日の予定名
  - 1日の収支
- 月単位の収支合計を色分け表示  
  （黒字：緑／赤字：赤）

### 📊 収支ダッシュボード
- 総収入
- 総支出
- 差引残高を一目で確認
